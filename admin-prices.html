Cách tạo token để lưu giá

Mở GitHub → tạo fine-grained token. Chọn tài khoản cotdostore, chỉ repo shopweb-test1.1. Trong Repository permissions, bật Contents: Read and write. Tạo token và nhập vào ô trên. Token chỉ được giữ trong bộ nhớ của tab đang mở; tải lại trang cần kết nối lại.
